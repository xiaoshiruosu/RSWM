# BenchmarkCard

## 目的与观察权限

RSWM 将静态 RGB 正射影像作为有限二维世界，检查数值空间控制、可见区保持、重访与状态恢复。序列是查询顺序，不是真实时间。I0 是唯一初始真实观测；模型只使用当前公共查询与自己协议允许的历史。Oracle 是 evaluator 仪器，不能作为普通生成方法。固定噪声地图的零一致性误差不证明图像质量或学习到记忆。

## 冻结几何与程序

5000² RGB → 中央4096² → 整数半向上 2×2 平均 → 2048²。视口240×416，uint8 RGB HWC，查询两轴±704，规范视口对角线归一化；起点(960,960)、(1088,960)、(960,1088)、(1088,1088)。原生成器、地理选择、标签和 RGB score 不改。

| 家族 | 程序 | 唯一新输出 |
| --- | --- | ---: |
| F2 | 32 新查询离线 | 32 |
| F3 | small 与 2×large，各32 | 64 |
| F5 | 96 在线，每调用16 | 96 |
| F7 | 32共同前缀、两个64后缀，独立restore | 160 |

核心120世界×4起点×4族=1920包；每模型/seed共168,960个新输出。正式测试仅SFO和Innsbruck共24世界、384包、33,792输出。K对真实I0，P对首次提交的冻结参考；128²目标像素首次计划曝光失败不能由后续输出补写。F7前缀只计一次。

## 结果和分析

expected固定分母与执行、资源、replay可信状态分开。v3首attempt是主分析；预算内恢复单独报告；全attempt成本不被成功重试覆盖。适用性NA、未测未知null、部分覆盖有不同字段。world与city权重保持既有 estimand，先报告两座测试城市，再作等城市平均；整world bootstrap、缺失上下界不得伪装为已观测误差。

运动与质量属于独立仪器，需Bellingham校准、Bloomington held-out验证和冻结接受规则。RGB一致性不能代替位移或真实分布质量。paired与native1024 LR64采用独立study及统计，不能借合并扩大核心样本。地理独立性在无地理证据时是unknown。
