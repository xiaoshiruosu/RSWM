# 数据源接入与优先级

本表为2026-09-12核查后的接入计划；不是已下载数据清单。详细来源链接与条款见根目录`plan.md`的S04–S20。

| 来源 | 用途 | 接入门槛 |
|---|---|---|
| Inria | 120世界核心；0.6m/px | 原始RGB TIFF、完整HF revision、精确大小和哈希；许可unknown须核查原始条款 |
| LandCover.ai | 优先第二源，先8–12大幅影像 | 原始RGB GeoTIFF，不用512裁块；地理重采样至0.6m；CC BY-NC-SA 4.0 |
| NLS Orthophotos | 芬兰独立地域补充 | 原生GSD≤0.6m、真实RGB、年度和地理参考；CC BY 4.0署名 |
| LINZ NZ Imagery | 新西兰跨来源补充 | 固定COG/STAC资产、测绘项目、GSD和具体供应方署名 |
| NAIP | 同尺度或独立1m主轨扩展 | 并非每资产满足0.6m；逐资产核查年度/许可/地理关系 |
| GLH-Water | 水域和低纹理压力集 | 大幅影像足够，但资产许可、来源和地理参考仍待确认 |
| LEVIR-CD+ | 独立1024²小地图轨 | 只读image1；固定100行；不得把第二时相当连续查询帧；重新设计F5/F7 |
| OpenEarthMap | 来源追溯和预训练污染审核 | 官方来源包括Inria与LandCover.ai；不能自动当作独立测试来源 |
| Genesis dense500 | 条件性多尺度候选 | 尚未确认完整数据发布和资产权利；不要编造下载地址 |

建议接入顺序为**Inria→LandCover.ai→NLS或LINZ**。LEVIR的三个test shard网页显示约1.316GB，不是精确字节清单；幅面更小并不意味着同一任务可直接运行。其Texas来源不能在缺少坐标时被断言与Austin无交叉。

所有下载都需先冻结元数据和权利证据，后裁世界、后采任务；硬错误中止构建，不能按模型结果更换源资产。低纹理与重复农田是测量条件，不作为自动丢弃理由。
