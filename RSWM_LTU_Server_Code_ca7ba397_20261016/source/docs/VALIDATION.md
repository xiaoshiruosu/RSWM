# 本轮验证报告

日期：2026-09-12。实现：`rswm-inria-120 0.1.0`。本报告只描述实际工程验证，不是实景遥感生成结果。

## 1. 环境与测试

Python 3.13.5；NumPy 2.3.5；Pillow 12.3.0；pytest 9.0.2；SciPy 1.17.0；PyTorch 2.10.0+cpu；CUDA不可用。

最后一次完整测试：**83 passed in 23.47s**。原始pytest文本和JUnit XML在交付ZIP的`evidence/`中；远端保存紧凑验证摘要。测试覆盖严格坐标、极限视口、随机任务重放、2倍配对、矩形朝向非不变性、首曝失败、分支共享历史锚、失败分母、标签防篡改、哈希链、5000²合成TIFF转换、运动弃权、未知块缺失与模拟生成接口。

这是参数化测试项总数，不是83项相互独立的研究发现。真实TIFF、真实特征网络和真实扩散/视频权重未用于本轮测试。

## 2. 全规模几何检查

以`geometry-fixture-000`到`geometry-fixture-119`作为**合成世界标识**，四起点分别构造F2/F3/F5/F7，共1920包、168960个计划新输出事件。没有候选上限耗尽；提案次数最大7。F5被接受的八个朝向计数为66、65、58、49、55、70、61、56，不宣称严格均衡。

本组任务目标首次再入事件范围85–96，不可见查询间隔62–76。固定未旋转完全重访示例的首次再入为92–95、间隔72–76、完整缺席调用数为3。参数化结果不能套用固定示例标签。

**此检查不等于已经选择和下载120幅Inria。** `hf_source_manifest_frozen=false`，`real_images_downloaded=0`。
