# RSWM-Bench 当前项目总结

**整理日期：2026-10-01。基线：`yedda-tv/rswm-1` 的 `codex/trained-wan-export@ddc1dd1868ac94cec9c3652bfec0f75f26003772`。**

## 1. 一句话定位

从一张局部遥感图像出发，让不同生成系统接受二维空间查询、持续生成有限世界；分别评价数值控制、首次公开内容保持、再入与分支、未知区域分布，以及计算和状态成本。

这是 Benchmark 论文路线，不再以单个相机 LoRA 方法为唯一贡献。旧 Wan/LingBot 工作是数值条件参考系统和机制分析对象。论文应证明任务能够区分真实系统行为，指标在明确范围内可信，且比较能排除条件编码、像素保护、缓存和生成顺序等替代解释；不要求自家方法总是胜出，也不能保证会议录用。

## 2. 冻结设计

| 内容 | 规格 |
|---|---|
| 主来源 | HF `blanchon/INRIA-Aerial-Image-Labeling` 的固定 revision |
| 世界处理 |5000² RGB TIFF → 中央4096² → 精确2×2半向上平均 → 2048² PNG |
| 规范视口 |240×416 |
| 起点 |每世界四个固定origin |
| 查询 |相对I0、xy两轴±704，固定视口对角线单位 |
| 数据角色 |60 train、12 dev、12仪器calibration、12仪器validation、24 test |
| 核心规模 |120世界、480 I0、1920任务包 |
| 训练索引 |3840个33视图clips，126720真实视图事件 |
| 正式测试 |每模型每推理seed384包、33792个新输出 |
| 小地图扩展 |LEVIR100-LR64，独立1024²原尺寸，不混主榜 |

F2：32个新查询，多段数值控制。F3：small/large严格两倍，独立reset，共64个新输出。F5：离开后逐像素首次再入，共96个新输出。F7：32共同前缀+两个64后缀，共160个新输出。

首次曝光是第一次**计划**出现；若当时输出缺失，之后不能补写首次参考。K对真实I0，P对首次公开生成值，N使用固定首次提交图块的独立分布评价。主分析固定first_attempt_only，恢复另列，失败保留分母，F7共同前缀不重复计算。

## 5. 尚未完成的是实际运行与科研交付

最新报告限定的已检查环境中，固定TIFF为0/2，真实pilot每方法0/704；没有目标GPU、真实Wan权重加载、train60训练和完整正式模型测量。不能据此断言其他服务器没有数据或权重。

| 剩余工作 | 为什么重要 |
|---|---|
| 实际服务器、数据、权重和预算 |没有可执行输入，不能由更多测试创造真实运行 |
| dev2像素与真实模型联调 |验证真实17/33帧、条件消费、自有历史、F7、显存和恢复 |
| 当前core120完整资产审计 |历史receipt不能直接给当前缺失的文件签收 |
| 真训练/恢复/导出再推理 |软件转换通过不等于真实受训模型可部署 |
| 正式特征与运动验收 |诊断特征和有限历史范围不自动支持全部论文主张 |
| 四类模型主实验、机制和LEVIR |真实行为差异与外部适用性是论文关键证据 |
| 自动表图和干净复现 |所有结论需要从保留结果重算，不能手工填数字 |

当前应写为：**软件交付已达到进入真实服务器联调的阶段；完整真实科研交付尚未完成。** 不建议用缺少定义的“完成95%”。

## 6. 建议固定的总目标

> 从DDC合法后继继续，完成当前core120、四类真实模型、真实训练恢复导出、正式运动/质量、预注册核心和机制/独立扩展实验；输出可复算表图、可安装代码和论文材料，并在干净环境验证。所有必需项逐项通过后，才报告 `RSWM_V0_1_RESEARCH_PACKAGE_ACCEPTED`。

三级签收：

- L0：软件基线保留——当前阶段，不是最终完成。
- L1：真实端到端工程验收——实际数据、权重、设备、协议、训练/推理/评价链成立。
- L2：科研包验收——正式矩阵、机制/外源、统计、复现、论文材料完成；本次总目标。

L2不包括保证录用、自动投稿、自动公开数据/权重或自动合并main。默认是可信内部科研包；实际numeric/GPU公共隔离未验证时继续明确security_verified=false。

Codex的持续工作规则：一个阶段完成后继续下一个可执行阶段；失败先定位，不以删测试或删样本通过；外部输入缺失则集中列出最小请求，继续独立任务；全部剩余都阻断时保存恢复游标，不伪造完成，也不无限重试同一通道。
