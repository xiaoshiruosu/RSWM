## 1. 从方法论文改成 Benchmark 论文：改什么，不改什么

已有方案实际上已经采用benchmark框架，不需要推翻数据与F2/F3/F5/F7。需要改变论文中的论证顺序、主实验和资源分配。

| 原方法主导叙事 | Benchmark主导叙事 |
|---|---|
| 提出某个记忆模块，构造数据证明它更好 | 定义待测能力与信息权限，公开协议，再比较多种合法实现 |
| 核心图是网络结构 | 核心图是任务、首次承诺、首次再入与评价流程 |
| 大部分篇幅介绍网络和训练损失 | 大部分篇幅解释构建、指标有效性、跨模型证据与限制 |
| 主表只有Ours优于若干基线 | 主表包含多范式的分项行为、覆盖、成本和解释边界 |
| 地图缓存天然保证的性质算算法创新 | 缓存作为合法机制，揭示系统保证与生成器能力的区别 |
| 不成功的实验不进正文 | 有效负结果、测量弃权与失败比例也是主要发现 |

推荐工作标题：**RSWM-Bench: Auditing Numerical Spatial Control and Persistent Commitments in Remote-Sensing Generation**。

这里RSWM-Bench是论文层面的基准套件名称建议，RSWM-Inria-120继续是固定核心配置；不改Python包名，不暗示第二来源已经建成。最终标题可保留Inria-120，但不应让标题承诺比实测范围更广的能力。

建议围绕三个贡献写作：

**C1 可复现任务基准。** 从真实连续正射影像建立数值空间查询、严格尺度配对、首次再入和共同前缀分支；公开数据划分、构建器和信息权限。

**C2 有解释边界的自动评价。** 区分观测、生成历史与未知内容；用不可补写的首次承诺、失败分母和独立测量验证，明确每项指标能证明什么、不能证明什么。不是把现有MAE重新命名为新指标。

**C3 基于强基线的实证发现。** 比较视频、数值条件生成、整图和增量地图，在同骨干机制实验和跨地域/跨来源测试中检验控制、保持、未知分布和成本的关系。

参考方法可以构成可复现性贡献的一部分，但不要求新架构或所有指标第一。没有真实实验时，C3只能写“拟检验”，不能提前写成发现。

## 2. 研究问题、邻近工作与新颖性核查

保持原RQ组织：RQ1数值空间控制；RQ2空间内容保持；RQ3条件与观测约束；RQ4生成范式与资源。未知分布诊断是对原RQ3/RQ4的补充，不替换为隐藏未来重建任务。

| 待检验问题 | 主证据 | 不足以支撑它的证据 |
|---|---|---|
| 给两倍位移，输出是否产生相应幅度响应？ | F3配对、图像独立运动估计及覆盖、数值条件消融 | prompt中写了“更快”、两组RGB不同 |

## 3. 固定核心规范与研究分层

### 3.1 不变的核心

| 配置 | 固定值 |
|---|---|
| 世界 | 原始5000² RGB TIFF → 中央4096² → 严格2×2平均 → 2048² |
| 名义GSD | 0.6 m/px；世界1228.8×1228.8 m，不是旧版1 m/px |
| 视口 | 高240、宽416，uint8 RGB HWC、无损保存 |
| 初始中心 | (960,960)、(1088,960)、(960,1088)、(1088,1088) |
| 相对查询 | q0=(0,0)，两轴[-704,704]，x右正、y下正 |
| 坐标单位 | sqrt(416²+240²)=480.2665926337163；不随任务或调用变化 |
| F2 | 离线32个新查询，2–4段折线 |
| F3 | small/large各32个新查询，large严格为2×small |
| F5 | online16，96个新查询，首次生成目标离开后重入 |
| F7 | online16，32共享前缀＋两个64后缀，共160个唯一新输出 |
| 首次目标 | B中心128²，逐像素first/reentry/gap标签 |
| 核心规模 | 120世界、1920包；测试24世界、384包 |

序列不是现实时间，不加入多时相预测、三维重建、卫星真实姿态或无限地图。源图有地理标签则保存，没有则不制造经纬度。单张局部图像无法唯一决定远处布局；未知区域不把隐藏未来RGB视为唯一答案。

### 3.2 三层组织，而不是混成一个总榜

**Core：** 完全保留RSWM-Inria-120，所有方法在相同角色、任务、协议、评分网格上测试。

**Audit：** Oracle、受控运动错误、历史重绘、首次失败、复制、噪声地图、状态污染；用于检验仪器，不当成真实生成模型主表。

**Extensions：** 已有same-start-return-pair；待建第二来源；可选online1或受限状态实验。分别登记study、版本和预算，不将扩展包计入1920。

只有Core不足以证明论文贡献；Audit和真实多模型实验是必要证据。增加扩展必须有具体研究问题，不按数据集/模型数量盲目扩张。

## 4. 本次代码审阅提出的优先风险

### 4.1 整图补全的起始顺序可能削弱基线

`baselines.py`的WindowMap(eager=True)按iy/ix从左上扫描。内部I0位于以(1024,1024)为中心的区域，首个512²上下文对应地图左上角附近，和I0无交集。因此前几个调用不可能通过该局部输入直接看到I0。这是代码路径所支持的分析，不是已完成的性能实验。

待做：保留raster-order旧结果，新增从真实已知区域边界向外扩展的frontier-order整图方法。先选邻接已知内容的核心窗口，再固定优先级与并列排序；整图与增量方法共享补全骨干、512上下文/256核心、采样步数和硬保护。记录每次调用可见真实像素、生成历史像素、未知比例和累计生成面积。比较Eager-Frontier与Lazy，另将Eager-Raster作为顺序消融。不要依据一个明显弱的整图策略得出“增量方法本质更优”。

### 4.2 当前运动仪器的搜索域也需要被校验

`motion.py`使用固定最小交叠0.65限制图像平移搜索；任务命令合法不代表模型实际运动也在该域内。输出若明显过冲，真实内容位移可能落在搜索域外。必须用域内、边界及域外受控位移检查是否错误地产生可信估计。

待做：在calibration比较当前仪器与固定更宽搜索域的候选仪器，或增加边界警报；所有模型使用同一冻结设置，绝不按命令中心搜索“正确位移”。验证失败时输出证据不足/歧义，不把边界估计硬判为真。不能改变搜索域后仍沿用旧仪器版本与校准结果。

### 4.3 函数存在不代表形成完整评价流水线

`quality.py`已有几何选块、首次台账组装与通用多项式MMD-U；没有据此得到冻结特征骨干和真实-真实基准。`stats.py`要求调用方先聚合为每世界一个值，不能直接喂逐帧记录。当前CLI主要执行RGB评测，运动、特征、成本、实验调度、结果表还要显式接线。

待做：建立run→replay→motion/quality/resources→world_summary→city_summary→tables的可追溯产物链。算法版本、模型权重和选择子集都写入索引，禁止依靠手工复制结果表。

### 4.4 全自动不等于完整语义有效性

保持原来不依赖人工逐图评分的约束。用受控构造、真裁剪和独立地域验证测量的操作语义。但自动特征距离不能单独认证每条道路、每栋建筑或灾害场景的真实性。论文应写“未知区域分布诊断”，而不是“准确评估全部地理语义”。

```bash

verify_manifest(m)

build_world(Path('data/source') / row['path'], row, 'data/first-world-check')
```

### Step 06｜全量下载与确定性世界转换

```bash
python -m rswm_inria.cli download --manifest data/manifest.json --out data/source
python -m rswm_inria.cli worlds --manifest data/manifest.json --source-dir data/source --out data/worlds
```

产物〔待做〕：leakage_audit.json、world_descriptors.parquet、geographic_groups.json。验收：无法确定的地理关系明确保留；测试不共享训练源像素，但不能声称基础模型预训练从未见过这些城市。

### Step 09｜验证首次出现、缺席和首次再入

产物〔待做〕：patch_plan、feature_manifest、real_reference_features、quality_report。验收：输出缺失不能改善采样，负的无偏MMD估计不擅自截零；只解释为选定特征和采样条件下的分布诊断，不解释为地理语义真值。

## 6. 评价定义与一项建议新增的失败敏感性分析

坐标交叠误差固定命令对应，不允许先最优平移对齐。已知保持对I0；历史保持对首次计划曝光槽位的有效值；首次再入逐像素只评价一次。F7两分支分别对共同前缀锚定，任一目标分支不完整则成对误差为空，同时给各支覆盖。

令M(u)为任意固定画布，在I0上等于真实观测，其余任意填值，系统始终返回crop(M,q)。只要全部输出合法，它的已知/交叠/历史/再入误差均为0。这一简单构造证明一致性不蕴含未知内容质量；它是指标解释命题，不包装成深奥理论创新。

**建议新增：有界RGB误差的缺失敏感性区间。** 当已评价RGB误差e∈[0,1]、计划像素有效覆盖c时，对未观测误差作任意[0,1]完成，全计划均值的保守可能范围为：

`[c*e, c*e + (1-c)]`。

推导：全计划均值=c*e+(1-c)*e_missing，且e_missing∈[0,1]。例如c=0.95、e=0.01，范围为[0.0095,0.0595]。它不是置信区间，不是把缺失真实赋值为1，更不修复缺失首次参考；只是展示“只报条件低误差”会隐藏多大不确定性。两端先按每任务计算，再用与主表相同的世界/城市权重聚合；不要用全局像素比替代等世界权重。仅适用有界RGB误差，不套到MMD或无界感知距离。

待做：独立实现该报告、加单测，并在随机缺失/按难度缺失的受控实验中展示其作用。原误差与覆盖仍是主结果，不形成总分。

## 7. 指标有效性应成为独立主实验，而不是附录单测

建议形成“受控错误—受影响指标—不应误伤指标—不可判定状态”矩阵。

| 受控构造 | 应检验的响应 | 解释限制 |
|---|---|---|
| 正确坐标真裁剪 | 合法对应RGB为0；有纹理时运动正确 | 真图低纹理允许运动弃权 |
| 反向/半幅/双幅 | 图像运动与命令不同，F3响应异常 | 同时裁错会改变已知区域；不假装单维扰动完全正交 |
| Copy I0 | 常有完美重复外观，但命令交叠/运动不同 | 重复图像差小不是正确位移 |
| 固定噪声地图 | 一致性可以完美，冻结质量诊断应有区分力 | 不能为迎合结论强制所有特征都区分 |
| 首次重入时重绘，最后再恢复 | 终点评分可能掩盖首次重入破坏 | 仅是操作层已知答案，不是真实模型发现 |
| 两分支共同替换旧目标 | 分支间相似但共同前缀保持失败 | 必须比较各支对前缀 |
| 首次输出缺失 | 首次参考永远无效，覆盖降低 | 后续正常不许补成成功 |
| 弱纹理/周期纹理 | 不充分证据或歧义，报告覆盖 | 不设法过滤源数据让仪器只见容易样本 |
| 拼接缝/模糊/颜色扰动 | 对各指标的敏感性分开报告 | 不把受控扰动等同于所有真实语义错误 |

还要做：参数扰动下的结论稳定性、样本数曲线、特征骨干敏感性、预处理一致性、随机种子变化、输出失败选择偏差。至少让两个不同生成机制的真实输出进入适用性分析；没有真位移标注时只能分析测量一致性和弃权，不能以模型命令充当真实输出运动。

## 8. 强基线配置与参考方法的重新定位

最低覆盖四类：无精确数值条件的视频、实际消费数值的生成器、真实整图补全、真实增量地图。建议目标为约6个实际系统配置、至少2–3个独立生成骨干；配置数不冒充独立模型架构数。

候选组合：Wan I2V；同骨干数值条件版；RemoteBAGEL；Genesis原生或合规适配；同一补全器的Eager-Frontier与Lazy。这是候选而非已复现名单。权重访问、许可、适配能力未通过时标出缺口，选择相同类别的可用替代并说明，不能用随机补全代替真实生成器。

数值条件参考实现建议：对(qx,qy,delta_x,delta_y)/固定对角线编码，通过选定生成骨干支持的条件注入位置接入；累计原点跨调用保持。采用预训练骨干的小规模领域适配，而不是只用60世界从零训练大模型。训练角色限定train，选参限定dev；公开注入位置、训练步数、可训练参数、teacher forcing与自主历史差异。当前仓库没有这套训练完成证据。LoRA/坐标编码本身不预设为论文创新。

同骨干机制实验固定数据、参数预算、推理步数、窗口、允许历史；保护I0与保护生成历史分别开关。模型运行时允许用自有历史，不能额外输入真实上一帧。输出resize属于方法的一部分并计成本；额外上下文帧、丢弃的原生帧、分支重放均计量。

| 优先级 | 实验/工程 | 直接回答的问题 | 主文证据 |
|---|---|---|---|
| P0 | 全自动指标有效性套件 | 测量可信吗、边界在哪里？ | 受控错误矩阵、可靠性/覆盖曲线 |

| P0 | 公平整图/增量对照 | 差异是范式还是补全顺序/窗口？ | Eager-Raster/Frontier/Lazy消融 |
| P0 | 失败与缺失分析 | 少输出是否能“获得更好分数”？ | 条件误差、完整分母、敏感性界 |
| P1 | 同起点完全/偏移配对 | 返回位置改变如何影响结果？ | 已有paired任务的真实推理结果 |
| P1 | 记忆组织与硬保护消融 | 保持源于什么系统机制？ | 同骨干能力—成本分项对照 |
| P1 | 第二来源与场景切片 | 结论是否依赖Inria风格？ | 独立外源表、两城分表 |

| P2 | online1、更多来源、更多规则 | 是否出现新的可解释研究问题？ | 独立扩展，不阻塞核心 |

“小改进”可以是固定坐标单位、从已知边界生成、空间缓存替代最近帧。要求先在dev预测它影响哪个指标，再锁定改动并检验测试；不要求超过所有模型，也不将工程修正夸大为新架构。若多项指标同时变化，报告折中而非只选有利项。

不建议作为主要工作量：再裁十倍帧、堆相近backbone、反复调prompt让自家方法赢、发明总分、给未知未来报PSNR、额外添加无法验证语义的规则。只有与问题、验证和外部可用性关联的投入才增强论文。

## 10. 第二来源与样本量策略

Inria继续是核心。建议增加一个大幅连续外源作为验证，不马上接十个小图集合。

| 来源 | 核验依据 | 接入方案 |
|---|---|---|
| LandCover.ai v1 [S8] | 波兰RGB GeoTIFF，33幅0.25m和8幅0.5m大图；CC BY-NC-SA 4.0 | 优先候选；按真实空间组冻结约24世界的外源目标，不能照搬Inria二倍下采样 |
| 芬兰NLS [S9] | RGB正射通常12000²、0.5m、EPSG:3067，CC BY 4.0 | LandCover不适用时的替代；每survey/年份、地理组记录，选择范围不按模型表现 |
| LINZ NZ [S14] | 按survey/region组织COG/STAC，GSD因资产而异 | 后续扩展；记录实际主层/overview、许可方与采集信息 |
| LEVIR-CD+ | 用户已有独立1024²小地图建议 | 不混主榜；必须新建轨迹与再入验证；不把第二时相当下一空间帧 |

外源建议匹配0.6m、2048²和公共视口，先确认源分辨率不粗于0.6m、真实连续范围足够，再做固定地理重采样。以空间组而不是瓦片数量作为主要多样性依据；24世界仅为预算目标，不保证拥有24独立地域。不得无依据宣称与所有预训练位置无交叉。

120世界“够不够”由效应大小、覆盖与区间稳定性判断。先做dev/校准期的世界数学习曲线与精度预算，再决定是否增加地理组。主测试只有两个城市，不能用更多同城起点解决地理外推证据不足的问题。测试不稳定时收窄结论或增加版本化独立地域，不根据测试方差临时挑城市。

## 11. Benchmark论文怎么写

建议主文结构：1 Introduction；2 Related Work；3 Task Definition and Design Principles；4 Benchmark Construction；5 Evaluation and Metric Validation；6 Baselines and Experimental Protocol；7 Results and Analysis；8 Limitations and Conclusion。

篇幅建议为引言/相关工作约20%，协议/构建/指标约40%，实验/分析约35%，限制/结论约5%。这是内部写作比例，不是会议官方规则。参考模型结构放在基线部分和附录，不能重新占据半篇主文。ICLR当前初稿正文上限9页；最终采用目标会议官方模板[S15–S17]。

**Introduction四段。** 第一段说明看起来连续的空间展开不保证精确位移或旧内容保持；第二段用近邻研究说明为什么需要本任务的精确二维对应与持续承诺；第三段介绍基准与测量层次，主动承认缓存合法和未知未来多解；第四段列C1/C2/C3，并且只把有实验的部分写成完成贡献。

**Benchmark Construction。** 依次写源与权利、地域划分、确定性转换、四任务、几何标签、信息权限和规模。明确是复用原始影像构造新任务，而非重新采集120幅影像或人工标注1920视频。

**Evaluation。** 给K/P/N、首次曝光、首次再入、共同前缀公式；各指标写reference、planned denominator、valid coverage、not_applicable和failure。紧接固定噪声反例与独立仪器验证，不把测量有效性完全藏进附录。

**Results。** 用问题组织子节，不用“Ours vs SOTA”组织整章。至少包括数值幅度、终点与首次再入区别、地图机制/顺序、未知分布与成本、两城及第二源、失败/敏感性分析。所有图都由固定manifest与脚本产生。结果支持不了原假设时如实写负结果，不倒推指标。

**图表规划。** 图1为问题与三个反例；图2为数据→任务→受限调用→首次台账→分项评价流程；图3为逐像素首次再入时间轴；图4为测量可靠性/覆盖；图5为能力与成本；表1为近邻定位，表2为数据/任务规模，表3为强基线分项结果，表4为机制与外源分析。按版面合并，不为了凑数量增加冗余图。

**摘要模板的逻辑。** 场景问题→现有评测缺口→提出固定协议基准→介绍首次承诺与分项测量→填入实际验证和多模型发现→公开可复算产物。没有结果时写[待填]，不得填入编造的百分比或“显著优于”。完整逐节提示与结果占位模板见 `docs/BENCHMARK_PAPER_BLUEPRINT.md`。

**限制必须写。** 静态二维而非普适世界理解；未知布局不唯一；仅两核心测试城市；预训练污染无法完全排除；自动质量诊断不等于语义真值；online16块内联合生成；显式地图可保证部分指标；进程内记录不等于安全沙箱。

## 13. 预算、排期和投稿路线

固定计算：每模型每推理seed测试33792图；3seed为101376图、30364139520原始RGB字节（约30.36GB）。6个真实系统×3seed为608256图、约182.18GB原始RGB；另有PNG、原生视频、临时张量、日志、权重和快照，不能把“小集合”当成低推理成本。训练clips3840只是索引数量，不是独立地理样本。

先用dev测每类任务初始化/每块/每窗口/恢复耗时，分别估计T_total=T_load+T_init+T_query+T_snapshot_restore+T_io。预留失败调查与重跑预算，但不虚构具体GPU型号、张数或小时数；当前材料没有给出这些硬件条件。

研究建议优先CVPR 2027。官方当前日期：CVPR注册2026-11-10、正文11-16、补充11-23；ICLR摘要2026-09-18、正文09-25，均AoE[S15–S17]。这是时间匹配建议，不是对某会议录用概率的断言；实质相似稿件不能违规并行评审。

## 14. 提交前必须满足的论文证据门槛

以下是本项目自定标准，不是会议承诺的录用条件：

G1：120真实世界及正式任务已构建；来源、版本、权利与地理限制清楚。
G2：至少四种生成类别真实运行，含实际消费数值条件的系统；Oracle/噪声不顶替。
G3：RGB与历史语义有独立核对；运动/质量在冻结校准和留出验证下有适用性证据。
G4：至少两项有清晰统计范围的实证发现，并通过不同模型或独立来源检验；不预设发现方向。
G5：同骨干地图比较处理好生成顺序、窗口、条件与资源混杂。
G6：原始分母、缺失、不可测、地理组、种子、模型/指标版本均可追溯。
G7：干净环境可重建和回放；全文没有把合成测试称为遥感模型实验。
G8：匿名、引用、数据/模型权利、AI使用披露和双投政策按目标会议执行。

这条路线的核心不是“为了中稿多做东西”，而是：让每个新实验排除一种合理替代解释，让每条论文结论都能被别人独立核验。
