The protocol follows the user's RSWM-Inria-120 specification. The image-only translation instrument is adapted from the user's previously delivered RSWM-Bench reference code; old experiments and test counts are not inherited. This version has its own test and validation evidence.

Synthetic fixtures are engineering controls, not remote-sensing images or empirical model performance. Public model evaluation requires a separate security boundary; this in-process reference runner is not a sandbox.
